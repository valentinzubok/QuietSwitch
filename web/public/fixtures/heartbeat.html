Key holder status

This page is a fixture in the QuietSwitch repository. It stands in for the page a key holder keeps updated, so that every check-in — and every silence — is a public commit anyone can diff.

About this page

The holder of the primary signing key publishes a short check-in here. The switch armed against this page does not care that the page exists; it cares whether the page states a check-in that satisfies the freshness rule recorded on chain. That distinction is the whole point: an abandoned status page keeps returning 200 forever.

Operational notes, deliberately verbose so the interesting line is not the first thing in the document: contact routes, escalation order, the on-call rota, the location of the hardware wallet, and the review cadence for this page. None of these are proof of life.
